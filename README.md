# Xray + 3x-ui (فارسی) — استقرار تک‌پورتی روی Defang.io

یک پروژه‌ی آماده‌ی تولید (Production-Ready) و داکرایز شده که یک **هسته‌ی Xray**
همراه با **پنل مدیریت وب 3x-ui (نسخه‌ی MHSanaei)** — локализ شده به **زبان فارسی** —
را پشت یک **ریورس‌پروکسی Nginx** اجرا می‌کند که هم رابط کاربری وب و هم ترافیک
پروکسی WebSocket را روی **یک پورت واحد (80)** چندپلکس می‌کند و آن را کاملاً با
پلتفرم PaaS مبتنی بر **Defang.io** سازگار می‌سازد.

```
 ┌────────────────────────────────────────────────────────────────────┐
 │                    لودبالانسر HTTPS دفنگ (Defang)                  │
 │                  (خاتمه‌ی TLS روی پورت 443)                        │
 └──────────────────────────────┬─────────────────────────────────────┘
                                │ HTTP ساده
                                ▼
 ┌────────────────────────────────────────────────────────────────────┐
 │                       کانتینر (پورت 80)                           │
 │                                                                    │
 │   ┌──────────────┐   /              ┌──────────────────────────┐  │
 │   │              │ ───────────────► │ پنل وب فارسی 3x-ui       │  │
 │   │              │                  │ (پورت 2053، داخلی)       │  │
 │   │    Nginx     │ ── /vless-ws/ ─► │ Xray VLESS-WS (10001)    │  │
 │   │  (پورت 80)   │ ── /trojan-ws/ ► │ Xray Trojan-WS (10002)   │  │
 │   │              │ ── (fallback) ─► │ صفحه‌ی HTML فیک (:8080)   │  │
 │   └──────────────┘                  └──────────────────────────┘  │
 └────────────────────────────────────────────────────────────────────┘
```

## ✨ امکانات

| امکانات | جزئیات |
|---|---|
| **رابط کاربری فارسی** | پنل 3x-ui به‌طور خودکار در اولین بازدید به فارسی (`fa-IR`) تنظیم می‌شود (تزریق از طریق `sub_filter` در Nginx) |
| **تک‌پورت** | فقط پورت 80 نمایش داده می‌شود — لودبالانسر HTTPS دفنگ TLS را خاتمه داده و HTTP را ارسال می‌کند |
| **VLESS-WebSocket** | اینباند پیش‌فرض روی مسیر `/vless-ws/` با Fallback به یک صفحه‌ی HTML فیک |
| **Trojan-WebSocket** | اینباند اضافی روی مسیر `/trojan-ws/` (اختیاری، آماده‌ی فعال‌سازی) |
| **مسیریابی مبتنی بر مسیر (Path-based routing)** | Nginx مسیر `/` → پنل، و مسیرهای `/vless-ws/` و `/trojan-ws/` → Xray را هدایت می‌کند |
| **رمز عبور خودکار ادمین** | در صورت تنظیم نشدن `ADMIN_PASSWORD`، یک رمز تصادفی تولید می‌شود |
| **ذخیره‌سازی پایدار** | پایگاه داده‌ی SQLite و لاگ‌ها از طریق Volumeهای نام‌گذاری‌شده در راه‌اندازی مجدد حفظ می‌شوند |
| **بررسی سلامت (Health check)** | بررسی سلامت داخلی `curl` روی پورت 80 |
| **محدودیت منابع** | تنظیم شده برای Defang Playground (512 مگابایت / 1 هسته CPU) |

## 🚀 شروع سریع — استقرار روی Defang

### 1. کلون یا دانلود این پروژه
```bash
git clone <your-repo-url> defang-xray      # یا آرشیو دانلود شده را از حالت فشرده خارج کنید
cd defang-xray
```

### 2. پیکربندی متغیرهای محیطی
```bash
cp .env.example .env
```
فایل `.env` را ویرایش کرده و **یک رمز عبور قوی برای ادمین تنظیم کنید**:
```bash
ADMIN_USERNAME=admin
ADMIN_PASSWORD=YourStrongPasswordHere123!
```
> اگر `ADMIN_PASSWORD` را خالی بگذارید، یک رمز تصادفی در اولین بوت تولید شده
> و در لاگ‌های کانتینر چاپ می‌شود. آن را با دستور زیر بازیابی کنید:
> ```bash
> defang tail xray-panel
> ```
> به دنبال خط حاوی `Password :` بگردید.

### 3. استقرار
```bash
defang deploy
```
دفنگ کارهای زیر را انجام می‌دهد:
1. ایمیج Docker را در خوشه‌ی بیلد ابری خود می‌سازد
2. آن را به رجیستری خصوصی خود پوش می‌کند
3. کانتینر را با Volumeها و Ingress پیکربندی‌شده، راه‌اندازی می‌کند
4. هنگامی که استقرار سالم شد، URL عمومی را چاپ می‌کند

خروجی نمونه:
```
 ✅ Service xray-panel is healthy
 🌐 https://xray-panel-<your-project>.defang.dev
```

### 4. دسترسی به پنل مدیریت فارسی
URL چاپ‌شده را در مرورگر باز کنید:
```
https://xray-panel-<your-project>.defang.dev/
```
- رابط کاربری در اولین بازدید به‌طور خودکار با **زبان فارسی** بارگذاری می‌شود.
- با اعتبارنامه‌های موجود در فایل `.env` وارد شوید.
- اگر زبان به‌طور خودکار تغییر نکرد، روی انتخابگر زبان (بالا-راست) کلیک کرده و **فارسی** را انتخاب کنید.

## 🔧 ساخت اولین کانفیگ VLESS-WS

کانتینر همراه با یک **اینباند پیش‌فرض VLESS-WS** عرضه می‌شود تا بتوانید فوراً
اتصال برقرار کنید. UUID پیش‌فرض در اولین بوت تصادفی‌سازی شده و در پایگاه داده‌ی
پنل ذخیره می‌شود. برای مشاهده یا سفارشی‌سازی آن:

### گزینه‌ی الف — استفاده از اینباند پیش‌فرض (سریع‌ترین راه)
1. وارد پنل فارسی شوید.
2. در نوار کناری به بخش **inboundها** بروید.
3. یک اینباند با نام `VLESS-WS-Default` می‌بینید که روی پورت `10001` گوش می‌دهد
   و مسیر WebSocket آن `/vless-ws/` است.
4. روی آیکون **QR code / اطلاعات** کلیک کنید تا جزئیات اتصال را ببینید.
5. لینک `vless://` را کپی کنید یا QR code را با کلاینت خود اسکن کنید.

### گزینه‌ی ب — ساخت یک اینباند جدید از صفر
1. در پنل، روی **افزودن inbound** کلیک کنید.
2. تنظیمات زیر را اعمال کنید:
   - **پروتکل**: `vless`
   - **پورت**: `10001` (یا هر پورت داخلی آزاد — اما باید با یک بلوک `location`
     در `nginx.conf` مطابقت داشته باشد)
   - **شبکه**: `ws`
   - **مسیر**: `/vless-ws/`
   - **امنیت**: `none` (TLS توسط لودبالانسر دفنگ مدیریت می‌شود)
   - **UUID کلاینت**: خودکار تولید می‌شود، یا می‌توانید خودتان تنظیم کنید
3. ذخیره کرده و اینباند را ری‌استارت کنید.

## 📱 پیکربندی کلاینت

از آنجا که **Defang در لودبالانسر خود TLS را خاتمه می‌دهد**، کلاینت شما روی
پورت **443** و از طریق **WSS (WebSocket Secure)** متصل می‌شود — حتی اگر کانتینر
داخلی فقط روی پورت 80 گوش دهد.

### فرمت لینک کلاینت VLESS-WS
```
vless://<UUID>@<defang-domain>:443?type=ws&security=tls&path=%2Fvless-ws%2F&host=<defang-domain>&sni=<defang-domain>#My-VLESS-WS
```

جایگزین کنید:
- `<UUID>` — UUID کلاینت از پنل
- `<defang-domain>` — دامنه‌ی اختصاص‌داده‌شده توسط دفنگ (مثلاً `xray-panel-xyz.defang.dev`)

### نمونه با مقادیر واقعی
```
vless://d342d11e-d424-4583-b36e-524ab1f0afa4@xray-panel-myproj.defang.dev:443?type=ws&security=tls&path=%2Fvless-ws%2F&host=xray-panel-myproj.defang.dev&sni=xray-panel-myproj.defang.dev#My-VLESS-WS
```

### کلاینت‌های پیشنهادی
| پلتفرم | کلاینت |
|---|---|
| ویندوز | v2rayN, Nekoray |
| مک | V2RayU, Foxray |
| اندروید | v2rayNG, NekoBox |
| iOS | Shadowrocket, Streisand, FoXray |
| لینوکس | v2rayA, Nekoray |

## ⚙️ نحوه‌ی عملکرد (بررسی عمیق معماری)

### چندپلکس کردن تک‌پورتی
دفنگ تنها یک پورت برای هر سرویس (HTTP/HTTPS) نمایش می‌دهد. برای سرو کردن هم‌زمان
پنل وب و ترافیک WebSocket مبتنی بر Xray روی همان پورت واحد، از **Nginx به‌عنوان
ریورس‌پروکسی مبتنی بر مسیر** استفاده می‌کنیم:

| مسیر درخواست | هدایت به | هدف |
|---|---|---|
| `/` | `127.0.0.1:2053` (3x-ui) | پنل مدیریت وب فارسی |
| `/vless-ws/` | `127.0.0.1:10001` (Xray) | ترافیک VLESS روی WebSocket |
| `/trojan-ws/` | `127.0.0.1:10002` (Xray) | ترافیک Trojan روی WebSocket |
| *(fallback)* | `127.0.0.1:8080` (Nginx) | صفحه‌ی HTML خوش‌خیم برای پروب‌ها |

### انتخاب خودکار زبان فارسی
پنل 3x-ui زبان رابط کاربری را در `localStorage` مرورگر و تحت کلید `lang` ذخیره
می‌کند. دستورالعمل `sub_filter` در Nginx یک `<script>` کوچک به داخل تگ `<head>`
از HTML پنل تزریق می‌کند که `lang=fa-IR` را **فقط در صورتی تنظیم می‌کند که قبلاً
تنظیم نشده باشد**، سپس صفحه را مجدداً بارگذاری می‌کند. این یعنی:
- اولین بازدید → به‌طور خودکار فارسی
- کاربر به‌طور دستی زبان را تغییر دهد → انتخاب او برای همیشه حفظ می‌شود

### مکانیزم Fallback در Xray
فایل `config.json` شامل یک بلوک `fallbacks` روی اینباند VLESS-WS است:
```json
"fallbacks": [{ "dest": "127.0.0.1:8080", "xver": 1 }]
```
اگر یک کلاینت به `/vless-ws/` **بدون** یک ارتقای معتبر WebSocket متصل شود (مثلاً
یک سانسور که endpoint را پروب می‌کند)، Xray او را به صفحه‌ی HTML فیک روی پورت
8080 هدایت می‌کند — که این endpoint را از یک وب‌سایت معمولی غیرقابل تشخیص می‌سازد.

### قوانین مسیریابی
کانفیگ Xray موارد زیر را مسدود می‌کند:
- **تبلیغات و ردیاب‌ها** (`geosite:category-ads-all`)
- **دامنه‌های بدافزار و فیشینگ**
- **دامنه‌های استخراج رمزارز (Crypto-mining)**
- **ترافیک BitTorrent** (مسدود کردن در سطح پروتکل)

و IPهای ایرانی و شبکه‌های خصوصی را مستقیماً (بدون پروکسی) مسیریابی می‌کند.

## 🔐 نکات امنیتی

1. **رمز عبور ادمین را تغییر دهید** — مقدار پیش‌فرض فقط یک جایگزین است. قبل از
   استقرار، یک رمز قوی در `.env` تنظیم کنید.
2. **TLS توسط دفنگ مدیریت می‌شود** — نیازی به مدیریت گواهی‌نامه‌ها ندارید. تمام
   ترافیک بین کلاینت و لودبالانسر دفنگ رمزنگاری شده است.
3. **فقط پورت‌های داخلی** — پنل 3x-ui (2053) و Xray (10001، 10002) فقط روی
   `127.0.0.1` گوش می‌دهند و از بیرون کانتینر غیرقابل دسترسی هستند.
4. **محدودیت منابع** — فایل Compose کانتینر را به 512 مگابایت / 1 هسته CPU محدود
   می‌کند که برای Defang Playground مناسب است. برای بار کاری تولیدی تنظیم کنید.
5. **Volumeها** — Volume با نام `xui-data` پایگاه داده‌ی پنل، اینباند‌ها و کانفیگ‌های
   کلاینت را در طول استقرارهای مجدد حفظ می‌کند. مگر اینکه بخواهید از صفر شروع کنید،
   آن را حذف نکنید.

## 🛠️ مرجع متغیرهای محیطی

| متغیر | پیش‌فرض | توضیحات |
|---|---|---|
| `ADMIN_USERNAME` | `admin` | نام کاربری ادمین پنل |
| `ADMIN_PASSWORD` | *(تصادفی)* | رمز عبور ادمین پنل. در صورت خالی بودن، یک رمز 24 کاراکتری تصادفی تولید می‌شود. |
| `PANEL_PORT` | `2053` | پورت داخلی پنل 3x-ui (باید با `nginx.conf` مطابقت داشته باشد) |
| `XRAY_VLESS_PORT` | `10001` | پورت داخلی برای VLESS-WS (باید با `nginx.conf` و `config.json` مطابقت داشته باشد) |
| `XRAY_TROJAN_PORT` | `10002` | پورت داخلی برای Trojan-WS |
| `XRAY_VLESS_PATH` | `/vless-ws/` | مسیر WebSocket برای VLESS |
| `XRAY_TROJAN_PATH` | `/trojan-ws/` | مسیر WebSocket برای Trojan |
| `TZ` | `Asia/Tehran` | منطقه‌ی زمانی کانتینر |

## 🩺 رفع اشکال

### پنل به فارسی بارگذاری نمی‌شود
- `localStorage` مرورگر را برای دامنه‌ی دفنگ پاک کنید، سپس صفحه را مجدداً بارگذاری کنید.
- یا روی انتخابگر زبان (بالا-راست پنل) کلیک کرده و **فارسی** را انتخاب کنید.
- بررسی کنید که بلوک `sub_filter` در `nginx.conf` موجود است (به‌طور پیش‌فرض هست).

### `502 Bad Gateway` پس از استقرار
- ممکن است پنل 3x-ui هنوز در حال راه‌اندازی باشد. 30 تا 60 ثانیه صبر کرده و رفرش کنید.
- لاگ‌ها را بررسی کنید: `defang tail xray-panel`
  - به دنبال خطوط `[init]` بگردید تا تأیید کنید مقداردهی اولیه تکمیل شده است.
  - اگر Nginx یا x-ui شروع نشدند، به دنبال خطاهای `supervisord` بگردید.

### اتصال WebSocket از سمت کلاینت ناموفق است
1. تأیید کنید که مسیر در کانفیگ کلاینت و تنظیمات اینباند پنل **دقیقاً** `/vless-ws/`
   (با اسلش انتهایی) است.
2. تأیید کنید که کلاینت از `security=tls` و `port=443` استفاده می‌کند (نه پورت
   داخلی 10001).
3. تأیید کنید که SNI/host با دامنه‌ی دفنگ شما مطابقت دارد.
4. لاگ دسترسی Xray را بررسی کنید: `defang exec xray-panel -- tail -f /var/log/xray/access.log`

### فراموش کردن رمز عبور ادمین
اگر از رمز تصادفی استفاده کرده‌اید:
```bash
defang exec xray-panel -- cat /etc/x-ui/admin-credentials.txt
```
اگر می‌خواهید آن را بازنشانی کنید:
```bash
defang exec xray-panel -- /usr/local/x-ui/x-ui setting -username admin -password NewPassword123
defang restart xray-panel
```

### تغییر مسیر WebSocket
1. فایل `nginx.conf` را ویرایش کنید — بلوک `location /vless-ws/ { ... }` را تغییر دهید.
2. فایل `config.json` را ویرایش کنید — `wsSettings.path` را در اینباند به‌روزرسانی کنید.
3. اینباند را در رابط کاربری پنل ویرایش کنید تا مطابقت داشته باشد.
4. استقرار مجدد: `defang deploy`

## 🧹 پاک‌سازی

برای حذف استقرار:
```bash
defang compose down
```
این کار کانتینرها را حذف می‌کند اما **Volumeهای نام‌گذاری‌شده را حفظ می‌کند**. برای
حذف همه‌چیز از جمله پایگاه داده‌ی پنل:
```bash
defang compose down -v
```

- **مستندات 3x-ui (فارسی)**: راهنمای داخلی پنل (آیکون `?`، بالا-راست)

در صورت بروز مشکل، یک تیکت در مخزن پروژه‌ی خود باز کنید و موارد زیر را ضمیمه کنید:
1. خروجی `defang tail xray-panel` (50 خط آخر)
2. دامنه‌ی دفنگی که به شما اختصاص داده شده است
3. برنامه و نسخه‌ی کلاینتی که استفاده می‌کنید
